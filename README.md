# NYC + NJ SMB Growth Platform

AI-assisted local-business growth platform for discovering underserved SMBs, auditing their digital presence, prioritizing leads, generating personalized website demos, and converting customers into recurring website/SEO/maintenance revenue.

## Phase 1

- Google Places ingestion for NYC + New Jersey
- Place ID deduplication
- Website existence/reachability checks
- Business Quality / Digital Weakness / Revenue Potential / Opportunity scoring
- Public business-contact email enrichment
- Lead tiers (S/A/B/C)
- Admin dashboard and CSV export

> Never commit API keys or private credentials. Use `.env.local` and deployment secrets.
